## 2. Three-gate scoring method (each packet)

1. **Headless capture at reference scale (never the owner's screen, mouse or focus).** Open each builder route on `http://127.0.0.1:8769/site.html?chrome=none#/app/word/...` in an isolated headless Playwright context at **`1349 × 922` CSS px** (`deviceScaleFactor: 2` → `2698 × 1844`, downsampled `× 5/12` to **`1124 × 768`**) for 1:1 pixel comparison with `owner/01..12.png`, at **`1380 × 922` CSS px** in `colorScheme: 'dark'` (`deviceScaleFactor: 2` → `2760 × 1844`, downsampled `× 5/12` to **`1150 × 768`**) for 1:1 pixel comparison with `owner/13-dark-home.png`, plus narrow (`320 × 800`) probe checks. Save captures, side-by-sides and crops in `dl-word/.shots/word-q147-eval/<packet>/`.
2. **Gate 1 — Whole-screen gestalt check (`W01.0`–`W13.0` FIRST, before any cell metric).** Place our `1124 × 768` (or `1150 × 768` for `W13`) capture directly beside the owner's PNG. Fail immediately anything a person would notice at a glance: wrong header or canvas tone, wrong ribbon card height or group widths, missing commands/icons/launchers/chevrons, monochrome or mis-proportioned icons, missing companion Copilot card or open Copilot pane or draft bar or rulers, wrong page width or Backstage proportions.
3. **Gate 2 — Observable region pass rules (zero `n/m`, zero out-of-scope):**
   - **Geometry (`G`):** `x, y, width, height`, paddings, group divider positions and gaps within **±2 px at `1124 × 768`** (**±2.5 CSS px at `1349 × 922`**).
   - **Colours (`C`):** Fill, border, active indicator and icon accent colours within **±3 per RGB channel** of the sampled owner PNG hex values below.
   - **Type (`T`):** Open-licensed UI sans (`Noto Sans Variable` / `Inter` metric match for proprietary `Segoe UI Variable` — recorded font-licence allowance), matching CSS size, weight, line height, cap-height (**±1 px at `1124 × 768`**) and tab/group/command label widths (**±2 px**).
   - **Custom Word icon pack (`I`, Q147.3):** Shipped as `packages/templates/word/icons/pack.json` through the public core `Icon` pack seam; newly drawn geometric SVGs (zero copied paths from `microsoft-icons`); button/slot box, ink bounding box (**±1 px**), stroke weight and multi-colour fills (**±3/ch**) match the reference screenshots and icon reference sheet.
   - **Enclosure & states (`E`):** Exact card radii (`8 CSS` / `6.5 PNG`), `1 px` borders/dividers, pressed/checked/disabled command states (`Print Layout`, `Vertical`, `Ruler`, disabled context commands), open `W05` gallery shadow, and zero extra or missing boxes.
   - **Completeness:** Every tab (`01`–`11`), popup (`05`), control, ruler, Copilot card, draft bar and Backstage section (`12`) is in scope; unbuilt screens or regions score **FAIL**.
4. **Gate 3 — Framework probes, regression sweep & core/template boundary (`Q147.4`):**
   - Preserve and verify `dl-word/.shots/regression/result.json` with `verify-sweep.mjs` (exit 0; zero unexplained diffs across other templates and library pages in light & dark).
   - Run browser probes on touched routes and audit `packages/core` changes (`npm run check` exit 0, `check:generic` clean, zero Word names or hexes in core, defaults unchanged).
