## 1. Benchmark and established scale

The benchmark is the owner's 11 PNG captures of the real Slack desktop app on Windows 11, stored git-ignored at `dl-brand-map/.design-library/slack-ref/owner/` (`01-slackbot-home.png` through `11-welcome-back.png`). **Privacy gate (Q146.1, Q146.3):** the reference PNGs contain real people's names, handles, avatars and workspace copy; they are never committed, packaged or published, and none of those identities appear in this tracker or in the template. ## 2. Method (each packet)

1. **Headless capture at reference scale (never the owner's screen, mouse or focus).** Open each builder route on `http://127.0.0.1:8768/site.html?chrome=none#/app/slack/...` in an isolated headless Playwright context at **`1359 × 1152` CSS px** (`deviceScaleFactor: 2` → `2718 × 2304`, downsampled `× 1/3` to **`906 × 768`**) for 1:1 comparison with the owner PNGs, plus responsive checks at `906 × 768` CSS px and `320` CSS px. Save captures, side-by-side pairs and crops in `dl-brand-map/.shots/slack-q146-eval/<packet>/`.
2. **Gate 1 — Whole-screen gestalt check (FIRST, before any cell metric).** Place our `906 × 768` capture directly beside the owner's `906 × 768` PNG (`S01.0`–`S11.0`). Fail immediately anything a person would notice at a glance: wrong column proportions, missing window chrome or shell rim, wrong density or message rhythm, missing banners/menus/modals/tabs/controls, flat or missing enclosures, wrong surface tone, clipped text or broken alignment. Measured cells come **after** this gestalt gate, never instead of it.
3. **Gate 2 — Observable region pass rules (zero `n/m`, zero out-of-scope):**
   - **Geometry (`G`):** `x, y, width, height`, paddings and gaps within **±2 px at `906 × 768`** (**±3 CSS px at `1359 × 1152`**).
   - **Colours (`C`):** Fill, border, badge and text core colours within **±3 per RGB channel** of the sampled owner PNG hex values below.
   - **Type (`T`):** Lato family; exact CSS size, weight (`400`, `600`, `700`, `800–900`) and line height; cap-height within **±1 px at `906 × 768`**.
   - **Icons (`I`):** Proprietary Slack glyph outlines are never copied (main ruling, 2026-11-12 04:17; open MIT/Apache-2.0 or library icons only). Button/slot box, ink bounding box (**±1.5 px at `906 × 768` / ±2 CSS px**), stroke weight, filled-vs-outline state, and stroke/plate colour (**±3/ch**) must match.
   - **Enclosure & depth (`E`):** Border width & colour, corner radius (**±1 px at `906 × 768`**), elevation shadow / backdrop scrim, and nesting depth match the screenshot. Enclosures visible in the owner's PNGs (bordered date divider pills, 9-item hover bar, full-outline rounded unfurl cards, reaction pills, filter pills, card outlines) are **mandatory** and never removed on generic VN3 grounds; extra boxes absent in Slack fail. **Evaluator rule (Main correction, 09:31):** score ONLY pixels sampled from the owner's 11 PNGs, never Slack conventions from memory or outside sources; one-sided accent borders remain banned ([brief](brief.md#design-constraints)).
   - **Completeness:** Nothing visible in any of the 11 screenshots may be marked `n/m` or out of scope. Any unbuilt screen, state, menu, modal or banner scores **FAIL**.
4. **Gate 3 — Framework probes, regression sweep & core/template boundary:**
   - Run the browser probes (`spacing`, `layout`, `noise`, `material`, `clipping`, `ui-states`, `scroll`, `context`, `visual`, `motion`) on touched routes; judge VN3/VN5 against the owner PNGs.
   - Preserve and independently verify the builder's `.shots/regression/result.json` with `.shots/slack-eval/verify-sweep.mjs` (exit 0; builder is sole writer of `.shots/regression/` unless a serial slot is agreed).
   - Audit `packages/core` vs `packages/templates/slack`: `npm run check` passes (`check:generic`, `check:parts`, `check:clipping`, `check:views`, `check:content`, `tokens:check`, `agent:index:check`), zero Slack names or brand hexes in core, core defaults unchanged.
5. **Report & sign-off:** Send the consolidated fail list (screen/region ID, crop path, expected vs actual, owning layer) to Worker 86, update this tracker, and send Main at most 3 plain lines. Sign off only when all 11 gestalt rows (`S01.0`–`S11.0`), all 8 shared shell rows (`C1`–`C8`), all 64 screen region rows (`S01`–`S11`), the sweep and the boundary audit pass. Even then, sign-off is the evaluator's verdict, never owner approval.

### Allowed differences

- **Invented people, copy, URLs, photos and workspace names (Q146.1, Q146.3):** generated or neutral portraits/illustrations, neutral workspace initials and invented channel/message text of matching length and line count.
- **Icon glyph outlines (main ruling, 04:17):** open-licensed or library glyphs matching box, ink size, stroke weight, fill/outline mode and colour.
