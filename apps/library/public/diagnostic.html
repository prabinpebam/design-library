Design Library diagnostic page

This page has no styles, scripts or fonts, so it opens even when the library app or its tokens are broken.

If the library app is blank or shows an error

  1. Reload the library app. The development server shows build errors in the page and in its terminal.
  2. Rebuild the tokens from the workspace root with npm run tokens, then check them with npm run tokens:check.
  3. Type-check the app with npm run typecheck.
  4. Restore the last reviewed slice from .design-library/snapshots/<slice>/ if a rejected change broke it.

Where things are

  • Intent, decisions and the review ledger: foundation plan in Slate.
  • Token source: packages/core/tokens/. Generated CSS: packages/core/css/tokens.css.
  • Library app source: apps/library/src/.
  • Server lifecycle and recovery: the setup guide in Slate, section “Library app server”.
